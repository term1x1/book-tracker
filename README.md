# 📚 Book Tracker — Telegram Mini App

Трекер книг: библиотека, статусы («Хочу прочитать» / «Читаю» / «Прочитано»), оценки, категории и статистика. Работает без сервера — данные хранятся в Telegram CloudStorage (привязаны к вашему аккаунту и синхронизируются между устройствами). При запуске в обычном браузере используется localStorage.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 — приложение полностью работает в браузере (данные в localStorage).

## Как подключить к Telegram

### 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя (например, «Мои книги») и username (например, `my_books_tracker_bot`).
3. Токен бота для этого приложения **не нужен** — сервера нет.

### 2. Задеплойте приложение

Mini App — это просто статический сайт по HTTPS. Самый простой бесплатный вариант — Vercel или Netlify:

```bash
npm run build
```

Содержимое папки `dist/` загрузите на любой статический хостинг, например:

- **Vercel**: `npm i -g vercel && vercel --prod`
- **Netlify**: перетащите папку `dist` на https://app.netlify.com/drop
- **GitHub Pages**: тоже подойдёт (в `vite.config.ts` уже стоит `base: './'`)

Скопируйте полученный HTTPS-адрес.

### 3. Подключите Mini App к боту

В [@BotFather](https://t.me/BotFather):

1. `/mybots` → выберите бота.
2. **Bot Settings → Menu Button → Configure Menu Button** — вставьте URL приложения и название кнопки (например, «Книги»).
3. (Опционально) `/newapp` — создать полноценное Mini App с коротким адресом `t.me/<bot>/<app>`.

Готово: откройте бота и нажмите кнопку меню — приложение запустится внутри Telegram, тема подстроится автоматически, данные будут храниться в облаке Telegram.

## Структура

- `src/App.tsx` — главный экран: вкладки, фильтры, поиск
- `src/components/BookForm.tsx` — добавление/редактирование книги
- `src/components/Stats.tsx` — статистика
- `src/storage.ts` — сохранение: CloudStorage (чанками по 4 КБ) + localStorage
- `src/telegram.ts` — обёртка над Telegram WebApp API

## Ограничения CloudStorage

Telegram даёт 1024 ключа по 4096 символов. Приложение режет библиотеку на чанки, так что реальный лимит — примерно 10–15 тысяч книг, на практике хватит с запасом.
